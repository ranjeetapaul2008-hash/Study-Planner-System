# Study-Planner-System
## Overview
Study Planner System is a Python-based console application that helps students organize their study schedule by managing subjects, tasks, and deadlines.

## Features
- ➕ Add new study tasks
- 📚 Organize tasks by subject
- 📅 Store study dates
- 📋 View all planned tasks
- 💻 Simple menu-driven interface

## Technologies Used
- Python
- Lists
- Loops
- Conditional Statements
- Functions

## Skills Demonstrated
- Problem Solving
- Python Programming
- Menu-Driven Programming
- Data Organization
